# Atlas / Workspace Runbook

> Synthetic documentation for the public TmuxDock demo.

## One workspace, three surfaces

| Surface | Use it for |
| --- | --- |
| Agent terminals | Keep Codex, Claude and shell tasks docked in tabs. |
| Session Files | Browse the fixed working root, edit and save directly. |
| Document previews | Open independent HTML and Markdown tabs. |

## Files without the window shuffle

1. Open **Session Files** from a session.
2. Use the root toolbar to create files and folders.
3. Drop a local folder into `imports/` to upload its contents.
4. Drag entries between folders to move them.
5. Use **Copy Full Path** or **Copy Relative Path** when sharing a location.

## Save, then inspect

HTML previews refresh requested resources after changes. Markdown uses VS Code's built-in renderer. Each explicit preview opens its own permanent tab in the active editor group. Split the view only when you choose to arrange it.

## Destructive actions stay explicit

Rename rejects an existing target. **Delete Permanently** displays a confirmation with the host and complete target path. The working root itself cannot be renamed or deleted.
